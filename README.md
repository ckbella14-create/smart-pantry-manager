# smart-pantry-manager
Smart Pantry Manager Android application for Richfield Graduate Institute of Technology Mobile App Development 700 project. 

## About the Smart Pantry App
Smart Pantry Manager is an Android application developed in Java that allows users to keep track of the ingredients they currently have in their pantry. Users can add, view, edit and delete pantry ingredients and manage recipes. The app also suggests recipes that the user can make based on the ingredients and quantities currently available in their pantry.

## Database option
Selected Database: SQLite

I selected the SQLite database to store the pantry and recipe data locally on the user's phone as it is easy to use, reliable and I've worked with it before so I'm already familiar with it. SQLite does not require an internet connection or an external database server, which will make it convenient for users. It was also the database approach covered in the Mobile App Development 700 module.

## Setup and run instructions

1. Clone or download the project from this GitHub repository.
2. Ensure that you have Android Studio installed.
3. Open the project in Android Studio.
4. Allow Android Studio to load and sync the project.
5. Connect an Android device with Developer Options and USB Debugging enabled, or start an Android emulator.
6. Select the connected device or emulator in Android Studio.
7. Run the application.
